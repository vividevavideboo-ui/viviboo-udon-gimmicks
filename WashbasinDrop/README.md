# Mashiro Washbasin Drop
エリアに入った人の頭上から、たらいを1個だけ落とすギミックです。落下と衝突音は全員に共有されます。

## できること
- エリアに入った最初のプレイヤーの頭上へたらいを落とす
- 落下中の重複出現を防ぎ、2秒後にたらいを回収する
- プレイヤーに当たったときだけ、全員に効果音を1回鳴らす

## セットアップ
1. エリア用の GameObject に `Collider` を付け、`Is Trigger` を有効にします。
2. 同じ GameObject に `Vivi > Washbasin Drop` を Add Component します。
3. Boothから用意したたらいをシーンに1個置き、`Rigidbody`、衝突判定用の `Collider`、`VRC Object Sync` を付けます。`VRC Object Sync` は所有権の譲渡を許可してください。
4. エリア側の **たらい** にそのGameObject、**衝突音** にAudioSourceを指定します。AudioSourceには効果音のAudioClipを設定します。
5. **衝突検知を追加して配線** を押します。たらいへ補助コンポーネントが追加され、Rigidbodyなどが自動で配線されます。
6. UnityのConsoleに赤いエラーが出た場合は、文面をそのまま共有してください。Unityが更新した `.asset` も動作確認後にコミットしてください。

## インスペクタ項目
| 項目 | 説明 |
| --- | --- |
| たらい | シーン内に1個だけ配置するたらい |
| Rigidbody | たらいの物理挙動用コンポーネント |
| VRC Object Sync | たらいの落下位置を同期するコンポーネント |
| 衝突音 | プレイヤーに当たったときに鳴らすAudioSource |
| 出現高さ | 頭上から落とし始める高さ |
| 表示時間 | たらいを回収するまでの秒数 |

## API リファレンス
| メソッド | 用途 | 呼び出し種別 |
| --- | --- | --- |
| `BeginDrop` | 同期した落下を開始する | 内部連携用・配線不要 |
| `HideWashbasin` | たらいを回収して同期する | 内部連携用・配線不要 |
| `NotifyPlayerHit` | プレイヤー衝突を通知する | 内部連携用・配線不要 |

## 注意点
- たらいのColliderは `Is Trigger` を無効にし、Rigidbodyには重力を有効にしてください。
- 落下中に別の人がエリアへ入っても、新しいたらいは出現しません。
- 同期を正しく行うため、たらいの `VRC Object Sync` では所有権の譲渡を有効にしてください。
